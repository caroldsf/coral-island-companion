# 🌴 Coral Island Companion

**Your island, your pace.**

Guia não oficial de Coral Island, criado para ajudar jogadores a planejar plantações e acompanhar seu progresso.

## Funcionalidades da versão inicial

- Perfil por estação e classificação da cidade, salvo localmente no navegador
- Filtro de plantações: selecionar várias estações mostra somente culturas compatíveis com **todas** elas
- Ocultação de conteúdo de classificações futuras (spoilers)
- Orientações sobre mudas frutíferas sazonais e árvores permanentes
- Calculadora simplificada de colheitas e lucro com valores editáveis
- Interface adaptada para celular

## Publicação no GitHub Pages

Em **Settings → Pages**, escolha **Deploy from a branch**, selecione **main** e **/(root)** e salve. Depois que o GitHub concluir a implantação, o endereço será:

https://caroldsf.github.io/coral-island-companion/

## Limitações atuais

Esta é uma versão inicial (MVP). O catálogo é parcial e os requisitos de classificação e períodos de produção devem ser conferidos no jogo e em fontes atualizadas. A calculadora não inclui qualidade, fertilizantes, múltiplos frutos por colheita ou mudanças de estação. Nenhum dado pessoal é enviado a servidores; as preferências ficam no localStorage do navegador.

Projeto independente feito por fãs, sem vínculo oficial com Stairway Games.
